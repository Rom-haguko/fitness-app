# Fitness App

Мультисервисное приложение для генерации тренировочных программ, отслеживания прогресса тренировок и анализа физической активности пользователя.

## О проекте

Fitness App — это система для автоматизированного формирования тренировочных планов и отслеживания прогресса пользователя.  
Проект использует микросервисную архитектуру и состоит из Java, Go и Python сервисов.

Основные возможности:

- генерация тренировочных программ;
- хранение тренировочных планов;
- отслеживание прогресса тренировок;
- сохранение веса пользователя;
- построение статистики и графиков;
- экспорт тренировочных планов в TXT/PDF.

---

# Уникальность проекта

Особенности проекта:

- использование микросервисной архитектуры;
- разделение ответственности между сервисами;
- автоматическая генерация тренировочных планов через Python-service;
- аналитика тренировочного прогресса;
- экспорт тренировочных планов в нескольких форматах;
- единая PostgreSQL база данных для сервисов.

# Архитектура проекта

Проект состоит из трёх основных сервисов:

## Java Service

Отвечает за:

- основную бизнес-логику;
- взаимодействие между сервисами;
- работу с пользователями;
- хранение тренировочных планов;
- REST API.

## Go Service

Отвечает за:

- сохранение прогресса тренировок;
- статистику;
- графики;
- экспорт TXT/PDF;
- работу с PostgreSQL.

## Python Service

Отвечает за:

- генерацию тренировочных планов;
- обработку пользовательских параметров;
- формирование структуры тренировок.

# Запуск проекта

Проект можно запустить напрямую через Docker Compose:

```bash
docker compose up --build
```

Также в проект добавлен `Makefile`, который упрощает работу с Docker Compose.

## Основные команды Makefile

Показать список доступных команд:

```bash
make help
```

Собрать Docker-образы всех сервисов:

```bash
make build
```

Запустить все сервисы:

```bash
make up
```

Собрать и запустить все сервисы:

```bash
make up-build
```

Запустить все сервисы в фоне:

```bash
make up-d
```

Остановить и удалить контейнеры:

```bash
make down
```

Остановить контейнеры без удаления:

```bash
make stop
```

Перезапустить проект с пересборкой:

```bash
make restart
```

Посмотреть список контейнеров:

```bash
make ps
```

Посмотреть логи всех сервисов:

```bash
make logs
```

Посмотреть логи отдельного сервиса:

```bash
make logs-java
make logs-go
make logs-python
make logs-db
```

Удалить контейнеры, volumes и orphan-контейнеры:

```bash
make clean
```

> Команда `make clean` удаляет volumes, поэтому данные PostgreSQL будут очищены.
